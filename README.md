# Smart Agriculture Platform

A full-stack AI-powered platform for soil health assessment, crop recommendation, fertilizer guidance, seasonal crop planning, weather prediction, and farmer assistance.

## Structure

- Backend: Flask API in backend/app.py
- Frontend: React + Vite app in frontend/
- Tests: backend/tests/test_app.py

## Run locally

### Backend

```bash
cd backend
C:/Users/selva/AppData/Local/Programs/Python/Python311/python.exe app.py
```

### Frontend

```bash
cd frontend
npm run dev
```

The frontend will be available at http://localhost:3000 and proxy API requests to http://localhost:5000.
